# Food — Healthy Food Delivery Service

A responsive web application for a healthy food delivery service. Users can choose a nutrition plan, calculate their daily calorie requirements, browse available meal plans, and submit a callback request.

## Live Demo

[Open Live Demo](https://food-umber-two.vercel.app/)

## About the Project

Food is a frontend web application created for a healthy food delivery service.
The project focuses on working with JavaScript, DOM manipulation, asynchronous requests, modular architecture, and automated project building with Gulp.

## Features

- 🥗 Nutrition plan selection
- 🔢 Calorie calculator
- 🍱 Dynamic meal cards
- 🎞️ Image/content slider
- 📑 Tabs
- ⏱️ Countdown timer
- 📞 Callback request form
- 💬 Modal windows
- 🔄 Asynchronous HTTP requests with Axios
- 📦 JSON data handling

## Installation

1. Clone the repository
`git clone https://github.com/LeonidHr/food.git`

2. Navigate to the project directory
`cd food`

3. Install dependencies
`npm install`

4. Start the development server
`npx gulp`

5. Build project
`npx gulp build`
